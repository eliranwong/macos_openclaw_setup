# Install HomeBrew

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Read https://brew.sh/ for details.

# Install Document Conversion Tools

Install `pandoc` and `texlive` for document conversion.

```
brew install git nano micro pandoc texlive
```

# Install Openclaw-related tools

```bash
npm install -g mcporter@latest
npm install -g clawhub@latest
npm install -g @steipete/summarize@latest
npm install -g @mariozechner/pi-ai@latest
```
